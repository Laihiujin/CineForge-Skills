# 60-second workflow

A practical short-form path:

1. Lock brief and one-sentence dramatic promise.
2. Build 6–10 beats; assign rough seconds.
3. Lock 1–3 characters and 1–3 recurring locations.
4. Lock visual language and reference hierarchy.
5. Build 10–20 shot rows, depending on pace.
6. Preflight continuity and reference conflicts.
7. Generate hero shots first, then connective shots and pickups.
8. Select before regenerating. Keep a generation log with rejection reasons.
9. Assemble picture, then sound design/music, then grade.
10. Run QC on individual clips and the final cut.

For 30-second model outputs, treat them as containers for timed sub-shots only when the model reliably handles internal cuts. Otherwise generate atomic shots and edit conventionally.
